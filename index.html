      ⚙️ Configuración

      🔑 Google Gemini

      La clave se guarda solo en tu navegador (localStorage). Consíguela gratis en Google AI Studio.

      🌐 Preferencias

      Muestra las voces en inglés instaladas en tu sistema. En Edge, las voces "Natural" (Online) suenan muy realistas. Prueba con 🔊 Escuchar en la pestaña Práctica.

      👥 Perfiles de usuario

      Cada perfil tiene sus propios historiales, progreso, rachas y nivel. La clave de API y los ajustes de voz son compartidos.

      💾 Respaldo de datos

      Exporta todos tus historiales, progreso y conversaciones a un archivo JSON, o restaura una copia previa. La clave de API no se incluye.

      🔄 Sincronización con archivo (File System Access)

      Vincula un archivo JSON de tu disco (p. ej. en OneDrive/Drive) y la app guardará automáticamente cada cambio. Compatible con Chrome y Edge de escritorio.

      ⚡ Respaldo local con Ollama (opcional, sin internet)

      Si Gemini no está disponible (sin internet o saturado), se usará tu Ollama local. Instálalo desde ollama.com y descarga un modelo con ollama pull llama3.2.

      📊 Uso de Gemini (plan gratuito)

      Contador local: la app registra cada petición que hace. El límite diario del plan gratuito se reinicia a medianoche, hora del Pacífico (PST/PDT).

      ⚠️ El contador es aproximado: solo registra las peticiones hechas desde esta app en este navegador. Si usas la clave en otros proyectos, el uso real puede ser mayor. Consulta los límites oficiales en ai.google.dev/pricing.
